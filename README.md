# The Java — an emigrant ship, 1839

The book by Stephen Michael Barnett (Ten Brat Press), maintained as plain-text
Markdown and built automatically into EPUB and PDF.

**Stephen:** you only ever need [GUIDE-FOR-STEPHEN.md](GUIDE-FOR-STEPHEN.md).

## How this repository works

```
manuscript/   the book itself — one Markdown file per chapter,
              built in filename order (00-…, 01-…, 02-…)
images/       photographs, maps, facsimiles (see images/README.md)
build/        metadata, stylesheet, and the build script
site/         the public download page (GitHub Pages)
.github/      the automation that builds the book on every change
```

Every push to `main` that touches the manuscript rebuilds the book and
updates the **latest** release, so these links always point at the
newest edition:

- `…/releases/latest/download/the-java.epub`
- `…/releases/latest/download/the-java.pdf`

The book can also be rebuilt by hand: **Actions → Build book → Run
workflow**.

## Building locally

Requires [Pandoc](https://pandoc.org) 3.x and [Typst](https://typst.app).

```
bash build/build.sh
```

Outputs land in `dist/`, including `the-java-extracted.txt` — the plain
text pulled back out of the EPUB, for diffing against the source to
verify the conversion changed nothing.

## Ground rules

- **The prose is never regenerated by software.** Conversion is done by
  Pandoc, which copies text verbatim. Editorial changes are made by
  humans, in the Markdown, where the commit history records them.
- Every image needs a caption with a credit line, and an entry in
  [PERMISSIONS.md](PERMISSIONS.md).
- One-time repo setup: **Settings → Pages → Source: GitHub Actions**
  (needed once before the download page publishes).
