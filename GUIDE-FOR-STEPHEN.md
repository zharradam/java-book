# Editing your book — the one-page guide

Your book lives in the `manuscript` folder, one file per chapter.
Everything else in this project is machinery you can safely ignore.

## To fix a typo or change some text

1. Open the `manuscript` folder and click the chapter you want.
2. Click the **pencil icon** (top right of the file view).
3. Make your change.
4. Click the green **Commit changes…** button, then **Commit changes**
   again in the box that appears.

That's it. A few minutes later a fresh EPUB and PDF are built
automatically — nothing else to do.

## The only three bits of "formatting" the book uses

| You type | You get |
|---|---|
| `# The Voyage Begins` | A chapter heading |
| `*Java*` | *Java* in italics |
| `![The Java at anchor. *Courtesy SLSA.*](../images/java.jpg)` | A photo with a caption |

Plain paragraphs are just plain paragraphs — type normally, leave a
blank line between them.

## To get the newest EPUB or PDF

Go to the **Releases** page (right-hand side of the project's front
page) — the newest files are always at the top. Or use the download
page, which always has the latest version.

## You cannot break anything

Every version of every file is kept forever. Any change can be undone
with one click, and Michael can always restore anything. Edit freely.

## If anything looks wrong

Email Michael. Include the chapter name and roughly what you were
doing — that's all he needs.
