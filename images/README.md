# Images

All photographs, facsimiles and maps for the book live here.

- Use lowercase filenames with hyphens: `java-1939-staveley.jpg`
- JPEG for photographs, PNG for maps/documents with sharp lines
- Aim for at least 1200px on the longest side — ereaders scale down
  gracefully but can't invent detail that isn't there
- `cover.jpg` in this folder becomes the EPUB cover and the download
  page image automatically

Every image needs a caption **with a credit line** in the manuscript,
and the permission to reproduce it should be noted in
`PERMISSIONS.md` at the repo root.
